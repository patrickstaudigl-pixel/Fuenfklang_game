# Fünfklang – Spielversion

Hier liegt nur der fertige Web-Build von **Fünfklang** zum Spielen im Browser – am Handy, Tablet oder PC, mit Touch, Tastatur oder Controller.

**Spielen:** https://patrickstaudigl-pixel.github.io/Fuenfklang_game/

Vorabversion: Grafik und Klang sind noch Platzhalter. Der Spielstand bleibt im Browser gespeichert.

Quellcode und Grafikpakete liegen nicht hier. Die Grafik stammt aus lizenzierten Paketen (siehe „Mitwirkende“ im Spiel) und darf nicht aus dem Build herausgelöst oder weitergegeben werden.
